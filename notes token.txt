- t_token *tokenize(char **split)
- static t_type get_token_type(char *str)
- int validate_tokens(t_token *tok)
- void free_tokens(t_token *tok)
- void display_tokens(t_token *tok)  // optionnelle pour debug


1️⃣ Création des tokens
Fonction : tokenize(char **split)

    Allouer une liste chaînée de t_token

    Pour chaque split[i] :

        Allouer un t_token

        Copier split[i] dans token->str

        Déterminer token->type via get_token_type()

        Gérer cas particulier :

            si précédent token est une redirection → FD ou LIM

            si début ou après un | → premier mot est CMD

            sinon WRD

        Lier les tokens entre eux (prev, next)

Fonction : get_token_type(char *str)

    Retourne le type de base du token :

        "|" → CMD

        ">" → ROUT

        ">>" → DROUT

        "<" → RINT

        "<<" → DRIN

        sinon → WRD

2️⃣ Validation de la syntaxe
Fonction : validate_tokens(t_token *tok)

Parcourt la liste et vérifie :

✅ Cas autorisés :

    cmd

    cmd | cmd

    cmd > file

    cmd >> file

    cmd < file

    cmd << limiter

🚫 Cas interdits :

    | cmd

    cmd |

    cmd | | cmd

    cmd >

    cmd > |

    cmd > < file

    cmd < > file

    cmd << << file

    cmd <> file

    double metachars sans WRD entre

Fonction utilitaires :

    is_redir(t_type type) → retourne si le token est une redirection

    is_metachar(t_type type) → retourne si le token est un metachar général (redir ou pipe)

3️⃣ Nettoyage
Fonction : free_tokens(t_token *tok)

    Libère proprement la liste chaînée

4️⃣ Affichage debug (optionnel)
Fonction : display_tokens(t_token *tok)

    Affiche la liste → très utile pour vérifier ton tokenizer\




    minishell> 'hgdiuj"'"'l"
Token 0: [hgdiujl]
minishell> "'l"
Token 0: [l]
